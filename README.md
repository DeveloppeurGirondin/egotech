# egotech
Site de présentation de la SASU EgoTech — Alexandre Urbain.

Site statique sans dépendance (HTML / CSS / JS vanilla), déployé sur GitHub Pages.

- `index.html` : contenu
- `css/style.css` : thèmes clair / sombre et mise en page
- `scripts/app.js` : thème, menu, animations, carrousel, filtres, lightbox

## Images à fournir
Les images manquantes s'affichent automatiquement sous forme d'emplacement en pointillés
indiquant le chemin attendu. Il suffit de déposer le fichier au bon endroit :

- `images/portfolio/betclic-goal-booster.webp`
- `images/portfolio/winestock.webp`
